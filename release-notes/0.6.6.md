Patter now checks recording permissions on launch and offers a compact setup dialog when access is missing.

- Allow microphone and computer-audio access before recording.
- Open the matching macOS settings when access was denied.
- Include Calendar and notification access when those features are enabled.
- Recheck when returning from settings, or choose Later to dismiss setup until the next launch.

Permission checks never start a recording or create a conversation. Unpackaged development builds skip launch setup.

Validated with 107 automated tests, app and documentation builds, packaged signature/entitlement checks, and browser interactions using simulated permission responses. Live macOS consent and capture still need a supervised check.
