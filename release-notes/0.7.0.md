Patter 0.7.0

Every new meeting summary now uses one format: **Summary**, with meaningful subsections for the topics discussed, followed by **Action items**. Concrete agreed or requested actions are listed even when no owner or deadline was stated. Owners and deadlines appear only when supported by the conversation; suggestions must not become invented commitments.

Remove template selection and custom-instruction editing from the meeting and Settings workflow. Existing custom templates, instructions, saved summaries, decisions, completed actions, notes, transcripts, recordings and history remain on disk. Old template instructions no longer affect new generation. Opening an existing meeting does not rewrite its summary. Regeneration keeps the previous version in history. No database migration or data deletion is introduced.

Manual regeneration, automatic processing after recording and local agent processing share the canonical prompt/schema. Older agent clients may still send a template argument; it is accepted but ignored for summaries. Invalid, incomplete or schema-echo responses preserve the previous summary.

Validation: 68 frontend tests and 77 routine native tests passed. An opt-in test separately passed a 23-second synthetic speech file through the production chunk writer, stop/finalization, installed Parakeet transcription, local Gemma summarization, SQLite save and reopening in an isolated library. It retained audio bytes and previous versions, produced four topic sections and three supported actions, and preserved prior generated content after simulated failed/empty captures. Three synthetic local-model cases also checked supported actions, missing owners/deadlines and declined suggestions.

The file-fed source replaced device input, and the processing core ran directly from the test. This was not a live microphone/system-audio or native UI permission test. Hardware startup, permission continuity, real meeting quality, long calls and sleep/wake reliability remain separate supervised checks. No private recording was uploaded or used during validation. The usual ad-hoc signing and macOS approval caveats still apply.
