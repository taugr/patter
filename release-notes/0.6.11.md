Patter 0.6.11

Keep the previous summary when a local model explicitly reports that its response reached an output limit or was filtered. Apply the check to intermediate summaries as well as the final response, so incomplete intermediate text cannot silently become a successful summary. Show a retryable error and retain conversation history.

Preserve compatibility with local servers that omit the finish reason, return null, or use an unrecognized value. Valid completed responses continue to save normally.

Validated with synthetic loopback model responses, native SQLite persistence and history checks, frontend tests and an isolated app UI check. No real meeting content, recording or paid model call was used. Full native checks and signed packaging run in the existing macOS release workflow.
