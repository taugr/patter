Patter 0.6.9

Overview now makes summary freshness visible after source text changes.

- Keep existing summaries, decisions and completed next steps when notes/title edits or successful manual re-transcription change the text supplied to the summarizer. Show a persistent **Source changed since this summary** notice with an explicit regeneration action.
- Capture the exact prepared summary job's source conversation, immutable revision and input projection version. Compare consumed title, notes and ordered transcript text; unrelated edits and identical re-transcriptions do not mark the source changed.
- Resolve freshness on native reads and save responses, including immediate unsaved drafts, reloads, restored versions and draft copies. Legacy or unavailable source provenance is shown as unknown. Existing libraries need no schema migration.
- Preserve previous content and freshness on failed regeneration and retain existing revision-conflict guards. Regeneration remains explicit and uses the existing local model configuration; it replaces generated fields while keeping immutable history.

Validated with synthetic native SQLite/service regressions and real React UI rendering through an isolated test transport with injected generated output. No real meeting library, audio recording or model inference was used. Full native tests and signed packaging run in the existing release workflow. Current releases remain ad-hoc signed without Apple notarization; permission continuity and real capture/inference retain their existing verification limits.
