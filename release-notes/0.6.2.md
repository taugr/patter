## Fixed in 0.6.2

- Adds the Calendar entitlement required by macOS Hardened Runtime. Its absence in earlier releases could prevent the consent prompt and leave Patter missing from Privacy & Security → Calendars. Patter remains ad-hoc signed; Apple notarization is not required for this fix.
- Release checks now inspect the built app's signature for the Calendar entitlement and its full-access usage description before publication.

## Simpler Settings

- Five focused tabs: General, Calendar, Models, Library and Agents.
- Shorter labels, fewer repeated explanations and expandable setup help.
- Save controls stay visible while the current tab scrolls. Switching tabs preserves unsaved edits, model downloads and backup state.
- Arrow keys, Home and End navigate the tabs. Connection and backup errors remain beside their controls.
- Updated setup and installation guides match the new locations.

## Updating

In an older Patter version, open **Settings → Updates → Install and restart**. In this version, Updates is under **Settings → General**. You can also download the DMG and replace the app in Applications. Existing conversations, recordings, settings and history are retained.

After updating, use **Settings → Calendar → Connect calendar**. If needed, expand **Connection help** for macOS Calendar permissions and Google account setup. Google Calendar must be enabled in macOS Internet Accounts, with events visible in Apple Calendar.

## Verification

The user confirmed that Calendar consent worked in a packaged local test build with the corrected entitlement. The new bundle check passes for that build and rejects the published 0.6.1 app as a negative control.

Frontend tests, production build and documentation build passed locally. In-app browser checks covered all five tabs, keyboard navigation, saved preferences after closing and reopening Settings, and compact layouts without horizontal overflow. Native download and backup flows were not rerun for the Settings rearrangement. Release CI runs the Rust and frontend suites and verifies the bundle, updater signature and published asset checksums.

Patter remains a personal preview for Apple Silicon Macs on macOS 15+, without Apple notarization. Live capture and model reliability across devices remain separate checks. Google Drive may need reconnecting after an ad-hoc-signed update; reuse your original Google Desktop OAuth setup JSON.
