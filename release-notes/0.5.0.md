## New in 0.5.0

- Connect Codex, Claude Desktop, Claude Code and other local MCP clients to Patter. The server is built into the Mac app; no extra runtime or network listener is needed.
- Nine tools for conversation search, notes/summaries/transcripts, version history, edits, summary templates, local processing, job status, navigation and app status.
- Agent access starts off. Enable library reading in Settings, with separate permissions for edits and local transcription/summaries. Keep Patter open while connected.
- Agent edits preserve recordings and version history. Revision checks reject conflicting edits; unsaved local drafts can be saved as separate conversations. Saved agent changes are attributed in history.
- Shorter Settings labels and fewer repeated explanations.
- Setup guides for Codex and Claude, including a copyable prompt to configure a local coding client while preserving existing settings.

## Connect an agent

Open **Settings → Agent access**, enable **Read entire library**, then expand **Connection setup**. Follow the [setup guide](https://github.com/taugr/patter/blob/v0.5.0/docs/agent-access.md) for your client.

Permissions apply to all connected agents under your Mac account. Read access includes archives and old versions. Cloud agents may send returned text to their model provider; Patter's own transcription and summaries remain local. Agents cannot delete data, start recording, access credentials or restore backups. Permission changes prevent running agent jobs from saving their results.

## Updating

Existing conversations, recordings, preferences and history are retained. Agent access must be enabled separately on each Mac. As with previous ad-hoc-signed updates, Google Drive may need reconnecting with your original Google Desktop OAuth setup JSON. Backup history and schedules are preserved.

## Verification and limits

Seven frontend tests and 44 Rust tests passed locally, alongside the production frontend build, native bundle signature checks, an official MCP SDK client and packaged-helper smoke tests. Checks covered permissions, concurrent edits, preserved audio/history, local fixture-model processing and native UI refresh/recovery. Release CI also tests, builds and verifies the updater signature and artifact checksums before publication.

The actual Codex/Claude client connection test was intentionally skipped for this release. Model-processing smoke tests used a local fixture; these checks do not establish long-meeting accuracy or real-model quality. Patter remains a personal preview for Apple Silicon Macs on macOS 15+, without Apple notarization.
