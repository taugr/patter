## New in 0.3.0

- Summary templates: General meeting, One-to-one, Interview, Brainstorm and Custom.
- Choose a default in Settings, edit each template's instructions, and override the template or add extra instructions for individual conversations.
- Templates guide every stage of long-transcript summarization. Generated versions retain the exact instructions, template and model used; previous summaries remain in history.
- A new teal SVG logo and matching Mac app icon.

Existing libraries continue with General meeting by default. No database migration or recording changes are needed.

Verified: production frontend build, five frontend tests, fourteen Rust tests, and browser checks for saved defaults, overrides, edits and resets. The summary pipeline test uses a mock local model; real model output quality remains to be checked with your chosen model.
