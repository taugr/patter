## New in 0.4.0

- Local Parakeet v3 transcription on Apple Silicon, with model downloads inside Patter. Whisper downloads and custom local model files remain available.
- Import an Anarlog 1.0.27 library, including notes, transcripts, summaries and retained audio. Preview the import first; unchanged repeat imports are skipped and existing Patter edits are preserved.
- Optional Google Drive backups: back up manually or at a chosen nightly time, including recordings, transcripts, generated summaries, version history and nonsecret settings.
- Restore a verified Drive backup with recording-path remapping and a retained safety copy of the previous library. Each Mac keeps its own library; backups do not synchronize edits.
- Background backups through a macOS LaunchAgent, including catch-up while Patter is closed.
- Clear recovery instructions when an app update requires Google Drive reconnection.

## Updating and Google Drive

Existing recordings and library history are retained. Because Patter is ad-hoc signed, a changed app build may lose access to its previous protected Keychain credentials. If prompted after updating, choose **Settings → Google Drive backup → Reconnect Google Drive**, select your original Google Desktop OAuth setup JSON and sign in with the same account. Keep that JSON available on each Mac. Reconnection preserves the backup destination, history and schedule, and resumes due backups.

Backup files are readable in your private Drive folder, without additional client-side encryption. Credentials, downloaded model weights and caches are excluded. Scheduled backups require the Mac to be awake, online and logged in.

## Verification and limits

Five frontend tests and 36 Rust tests passed before release. Live Google OAuth, a 22-file Drive backup and restore, recording hash checks, closed-app background backup and reconnection after a local test update have passed. The release workflow additionally checks the macOS bundle, updater signature and downloaded artifact checksums.

Patter remains a personal preview for Apple Silicon Macs on macOS 15 or later, without Apple notarization. Exact nighttime scheduling, sleep/login recovery, a second physical Mac, long recordings and device changes still need broader reliability testing. The local update/reconnection test does not substitute for testing this published build on every Mac.
