Recording now keeps the chosen conversation or calendar meeting, and upcoming meetings refresh when returning to Patter.

- Record from a selected conversation or directly from an upcoming meeting. The confirmation names where the audio will be saved.
- Repeated clicks cannot start duplicate recordings or create duplicate calendar conversations. Failed starts show an inline error and can retry in the same conversation.
- Interrupted recordings retain a recovery action. Additional recordings append to the conversation's existing audio timeline and preserve earlier notes and transcripts.
- Successfully finalized recordings automatically transcribe with the selected local transcription model, then generate the existing summary, decisions and action items using the configured local summary model and template.
- Processing progress and failures are visible. Resume after reopening Patter, or retry only the summary after a summary failure, without transcribing the same audio again. Empty, failed or interrupted captures do not automatically start processing; transcripts with no speech or insufficient content skip automatic summaries.
- Upcoming meetings support foreground and manual refresh, retain the last good list when Calendar cannot refresh, expose more meetings, and preserve invitation-derived join links.

Validated with 119 automated tests, app and documentation builds, packaged signature/entitlement checks, and desktop/compact UI flows using synthetic meetings, audio and model responses. Real audio capture, live Calendar fetching and actual model inference remain separate supervised verification tasks. Existing providers and preferences are unchanged; existing recordings are not automatically processed on launch.
